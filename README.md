# Welcome!
## Rocket Simulator
This is a custom-made rocket simulator, made entirely with python. Unfortunately, GitHub Pages doesn't run Python, so here are some instructions to access it anyway. I couldn't get the launch scenario to work correctly, so currently, it's just a docking simulator.

### Contributing
If you are interested in helping improve this simulator, simply fork it. There is a ruleset in place, and I will review the commits personally before merging. Please help!

### Download instructions
If you want to run this simulator, access it in GitHub Desktop. Repository Link: ```https://github.com/Waldrop29/RocketSim/``` Simply download it, open it in VS Code, and then run `python rocketsim.py` in the shell. You will need pygame installed in order to run it. 

### Hardware Requirements
You will need the T. Flight HOTAS 1, 4, or X. Other Thrustmaster models will not work. There are other models that will work, but they are not Thrustmaster. The rule of thumb is that they can only have 1 USB Cable. It should be a 6 analog axis HOTAS. If you don't have it, you can use your keyboard instead. Instructions for that are at the bottom of the simulation when you load it.
###### Note
You can fly this simulator without the rudder pedals, just use the other axes that you would use for yawing a plane in MSFS.
