# Welcome!
## Rocket Simulator
This is a custom-made rocket simulator, made entirely with python. Unfortunately, GitHub Pages doesn't run Python, so here are some instructions to access it anyway.

### Fork
If you are interested in helping improve this simulator, simply fork it. There is a ruleset in place, and I will review the commits personally before merging.

### Download instructions
If you want to run this simulator, access it in GitHub Desktop. Repository Link: ```https://github.com/Waldrop29/RocketSim/``` Simply download it, open it in VS Code, and then run `python rocketsim.py.' You will need pygame installed in order to run it.
